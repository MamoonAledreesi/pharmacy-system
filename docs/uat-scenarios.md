# سيناريوهات اختبار القبول (UAT)

تُجرى يدوياً على النسخة المثبّتة قبل التشغيل الفعلي، من مستخدم بكل دور. لكل سيناريو الخطوات والنتيجة المتوقعة. علّم ✔ عند النجاح واكتب الملاحظات عند الفشل.

**التجهيز**: نظام جديد بعد الإعداد الأولي، أنشئ مستخدمين: `cashier` (كاشير)، `pharm` (صيدلي)، `acc` (محاسب)، `store` (أمين مخزن).

## 1) الإعداد والمنتجات
| # | الخطوات | النتيجة المتوقعة | ✔ |
|---|---|---|---|
| 1.1 | مدير: الإعدادات ← غيّر اسم الصيدلية واللون ← حفظ | يتغيّر الاسم واللون فوراً ويظهر في الفواتير | |
| 1.2 | أنشئ منتجاً "بنادول" بوحدة شريط ووحدة علبة = 4 أشرطة، مع صلاحية | يُحفظ، وفي القائمة وحدتاه ظاهرتان | |
| 1.3 | حاول إنشاء منتج بنفس الباركود | رسالة خطأ تمنع التكرار | |
| 1.4 | غيّر اللغة إلى الإنجليزية ثم العربية | كل الشاشات تنقلب (اتجاه الصفحة والنصوص) | |
