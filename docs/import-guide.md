# دليل استيراد المنتجات والمخزون من Excel

الصفحة: **الأدوية والمنتجات ← قائمة المنتجات ← استيراد من Excel** (تحتاج صلاحية إدارة الكتالوج `Catalog.Manage`؛ وتسجيل الكميات يحتاج أيضاً `Inventory.OpeningStock`، وبدونها يُستورد الكتالوج فقط).

## الخطوات
1. **نزّل القالب** من الصفحة نفسها (بلغة الواجهة الحالية). فيه ورقة "المنتجات" بعمودها العشرين وسطرَي مثال، وورقة "التعليمات".
2. **املأ الملف**: سطر لكل منتج. لدفعة إضافية من نفس المنتج أضف سطراً جديداً بنفس الاسم والتركيز وغيّر الدفعة والصلاحية والكمية والتكلفة.
3. **ارفع الملف**: يظهر فحص كامل قبل أي حفظ: عدد المنتجات الجديدة والموجودة والدفعات، وكل سطر فيه حالته (جاهز / تنبيه / خطأ) وسببه بالعربية. الأسطر التي فيها مشاكل تظهر أولاً.
4. **أكّد**: "استيراد الكل" إن لم تكن هناك أخطاء، أو "استيراد الأسطر السليمة فقط" ليُستورد ما صحّ ويُرفض الباقي.
5. إن رُفضت أسطر فنزّل **ملف الأسطر المرفوضة** (بنفس الأعمدة وعمود أخير بسبب الرفض)، صحّحه وارفعه من جديد.

## الأعمدة
| العمود | ملاحظات |
|---|---|
| الاسم العربي / الإنجليزي | يكفي أحدهما |
| الاسم العلمي، التركيز، الشركة | اختيارية |
| الفئة | **مطلوبة للمنتج الجديد**، تُكتب باسمها كما في القوائم المرجعية (عربي أو إنجليزي) |
| الشكل الدوائي | اختياري، بالاسم |
| الوحدة الأساسية | **مطلوبة**: أصغر وحدة تبيعها (شريط، حبة…) |
| الوحدة الأكبر + عدد الأساسية فيها | اختيارية (علبة = 4 مثلاً)، والعدد 2 فأكثر |
| سعر البيع | للوحدة الأساسية |
| باركود الأساسية / الأكبر | اختياري، يحتفظ بالأصفار في أوله |
| الحد الأدنى للمخزون | اختياري |
| له صلاحية | نعم/لا، وإن تُرك فارغاً فهو نعم |
| رقم الدفعة، تاريخ الانتهاء، الكمية، وحدة الكمية، تكلفة الوحدة | المخزون الافتتاحي (اختيارية معاً). وحدة الكمية: فارغة أو اسم الأساسية = أساسية، واسم الأكبر = العبوة. التكلفة لوحدة واحدة من الوحدة المختارة |

التاريخ: تاريخ Excel، أو `2027-06-30`، أو `30/06/2027`، أو شهر وسنة `06/2027` (آخر يوم في الشهر). الأرقام تُقرأ بأي شكل (`1,250.50` و`1250,5` والأرقام العربية).

## قواعد مهمة
- **المنتج الموجود** (نفس الباركود، أو نفس الاسم والتركيز) **لا يُعدَّل**؛ يُضاف فقط مخزون أسطره.
- كل منتج جديد وكل دفعة يمرّان عبر نفس خدمات النظام (قواعد الأسماء والباركود والصلاحية والتكلفة وسجل الحركات والتدقيق).
- **رفع الملف نفسه مرة ثانية آمن**: لا يتكرر المنتج ولا يُضاف المخزون مرتين، فإن انقطع الاستيراد في منتصفه أعد رفع الملف نفسه ليُكمل.
- يُحفظ كل منتج وكل دفعة على حدة؛ فشل سطر لا يلغي ما سبقه، ويظهر في تقرير الرفض.
- الحدود: ملف xlsx حتى 5 ميجابايت و5,000 سطر.
- بعد استيراد كبير شغّل **الإدارة ← فحص الحسابات** للتأكد من تطابق الأرصدة.

## الأداء
استيراد 3,000 منتج بدفعة لكل منهما استغرق نحو 163 ثانية (الفحص 0.13 ثانية)، وتظهر نسبة التقدم أثناء الاستيراد. لملفات كبيرة جداً قسّمها إلى ملفات أصغر.
